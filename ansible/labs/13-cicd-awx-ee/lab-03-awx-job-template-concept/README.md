# Lab: Desain Arsitektur Job Template & RBAC di AWX/AAP

## Tujuan Lab
Merancang pemetaan arsitektur AWX: Project Git sync, Machine Credentials, Vault Credentials, Inventory, dan Job Template.

## Prasyarat
- Paham konsep orkestrasi terpusat berbasis Web UI

## Langkah-langkah Pengerjaan
1. Buka file referensi `job-template-notes.md`.
2. Rancang skema pemisahan hak akses (RBAC) antara tim System Administrator dan Application Developer.
3. Lengkapi spesifikasi job template untuk deployment aplikasi produksi secara terperinci.

## Kriteria Berhasil (Checklist)
- [ ] Spesifikasi pemetaan artefak AWX terdokumentasi dengan jelas
- [ ] Prinsip least privilege dalam manajemen credentials dan RBAC terpenuhi

## Ringkasan materi
`yamllint` adalah perkakas baris perintah linter untuk memverifikasi keabsahan sintaks, format baris, spasi, dan konsistensi file YAML sebelum dieksekusi oleh Ansible. Tool ini membantu menemukan kesalahan umum yang sering luput dari pandangan, seperti penggunaan karakter tab terlarang, spasi berlebih di akhir baris (trailing spaces), indentasi yang tidak konsisten, atau baris teks yang melebihi batas panjang karakter. Konfigurasi aturan dapat disesuaikan melalui file `.yamllint` di root repositori untuk menonaktifkan atau melonggarkan aturan tertentu. Menjadikan `yamllint` sebagai langkah pertama dalam proses pengujian kode memastikan basis kode selalu rapi dan bebas dari parse error.

## Contoh singkat
```bash
# Menjalankan yamllint pada seluruh file playbook di dalam folder
yamllint .
```
